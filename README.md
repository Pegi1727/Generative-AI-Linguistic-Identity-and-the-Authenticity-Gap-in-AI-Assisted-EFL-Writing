## 1. Overview of the Study

This dataset supports a mixed-methods study investigating the impact of Generative AI—specifically GPT-4o–assisted revision—on the linguistic identity, perceived authenticity, and agency of advanced EFL learners in Iran (*N* = 60).

Using an *explanatory sequential mixed-methods design*, the study examines:

1. **Linguistic metrics:** Accuracy and complexity from *Raw Voice* to *AI-Revised Voice*.
2. **Psychological metrics:** Identity-related effects measured using the Authenticity Gap Scale (AGS).
3. **Qualitative insight:** In-depth semi-structured interviews with a purposive subsample (*n* = 15).
